# STM32-LED_running-lights_test
作业/Homework
作业。演示LED流水灯效果。其中A5，A7，A9，A10为四个LED灯，通过检测A6电平情况作为判断按键（接入B12）是否被按下（知识储备有限...抱歉），通过切换state的加减实现正逆序流动
Homework. Demonstrate the LED running light effect. A5, A7, A9, and A10 are four LEDs. By detecting the voltage level of A6 as a judgment for whether the button (connected to B12) is pressed (limited knowledge base... sorry), the forward and reverse flow is achieved by switching between incrementing and decrementing the state.
